# 🤖 ChatGPT‑Powered AI Desktop Virtual Assistant

An AI-powered **desktop virtual assistant** built using **Python**, **Tkinter**, and **OpenAI’s ChatGPT API**.  
The assistant listens to your voice, understands natural language using ChatGPT, and replies with spoken responses.

---

## 🚀 Features
- 🎤 Voice input using microphone
- 🧠 ChatGPT-powered intelligent responses
- 🔊 Text-to-Speech (offline using pyttsx3)
- 🖥️ Desktop GUI built with Tkinter
- 💬 Conversation memory during session
- ⚡ Non-blocking UI using multithreading
- ❌ Exit anytime with button or command

---

## 🛠️ Tech Stack
- Python 3
- Tkinter (GUI)
- OpenAI Chat Completions API
- SpeechRecognition
- pyttsx3 (Text-to-Speech)
- PyAudio
- Threading
