# Plagiarism Detection Using Python

This project detects plagiarism between text documents using NLP techniques.

## Technologies
- Python
- Scikit‑Learn
- TF‑IDF
- Cosine Similarity

## Features
- Detects similarity between multiple documents
- Displays similarity percentage
- Configurable plagiarism threshold

## How to Run
1. Put `.txt` files into the `data/` folder
2. Run:
   python plagiarism_detector.py
